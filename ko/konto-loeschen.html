Tamdotti 계정 삭제

Vidomedia UG (haftungsbeschränkt)의 앱 ‘Tamdotti’에서 계정과 관련된 모든 데이터를 삭제하는 방법이에요.

앱에서 바로 계정 삭제하기

가장 빠른 방법은 앱에서 삭제하는 거예요. 즉시 삭제돼요:

  1. Tamdotti를 열고 계정으로 로그인하세요.
  2. 아래 바에서 더보기을(를) 누르면 설정이(가) 열려요.
  3. 맨 아래 계정 삭제 영역까지 스크롤한 뒤 계정 영구 삭제을(를) 누르세요.
  4. 삭제되는 내용을 읽고 계속을(를) 누른 다음 영구 삭제(으)로 확인하세요.
  5. 완료: 계정이 삭제됐어요 메시지가 보이고 로그아웃돼요. 계정과 모든 클라우드 데이터가 삭제됐어요.

‘계정 삭제’ 영역은 로그인했을 때만 보여요. ‘이 기기의 게임도 초기화하기’을(를) 선택하지 않으면 기기의 게임은 그대로 남아요.

앱 없이: 이메일로 삭제 요청

Tamdotti 계정 삭제는 언제든지 무료로 이메일을 통해 요청할 수 있어요.

  1. info@vidofood.de로 이메일을 보내 주세요. 가능하면 계정에 연결된 이메일 주소에서 보내 주세요. 제목: Tamdotti 계정 삭제
  2. 계정의 이메일 주소와 로그인 방법(이메일, Google 또는 Apple)을 알려 주세요. 앱 안의 사용자 이름을 알고 있다면 함께 적어 주시면 도움이 돼요. ‘Apple로 로그인’에서 이메일 가리기를 사용했다면, 전달용 주소는 Apple ID 설정의 ‘Apple로 로그인’에서 확인할 수 있어요.
  3. 본인의 요청인지 간단히 확인한 뒤 계정을 삭제해요. 확인 메일은 늦어도 한 달 안에, 보통은 훨씬 빨리 받아 보실 수 있어요.
이메일로 삭제 요청하기

무엇이 삭제되나요?

계정을 삭제하면 서버에 저장된 계정 데이터를 모두 영구적으로 지워요.

  • 사용자 계정과 로그인 정보(이메일 주소, 비밀번호 해시 또는 Google/Apple 연결)
  • 프로필(사용자 이름, 표시 이름, 친구 코드, 아바타, 시간대, 방해 금지 시간, 푸시 토큰)
  • 클라우드 저장 데이터, Dotti, 능력, 코인, 트로피, 인벤토리, 코인 거래 내역
  • 친구 관계와 친구 요청
  • 참여했던 방문, 전투, 대결 기록과 미니게임 점수
  • 공유 Dotti 그룹 멤버십과 예약된 알림

삭제 후에는 게임 데이터나 계정 데이터를 전혀 보관하지 않아요. Tamdotti에는 현금 결제가 없기 때문에 결제 데이터를 보관할 의무도 없어요. 서버 제공업체의 단기 기술 로그는 잠시 뒤 자동으로 삭제되고, 백업 사본이 있다면 정기 백업 주기에 따라 덮어써져요. 삭제 요청 이메일은 처리했다는 사실을 증명하는 데 필요한 기간 동안만 보관해요.

참고: 삭제는 되돌릴 수 없어요. 진행 상황, Dotti, 코인이 모두 사라져요.

기기에 있는 데이터

계정 없이 플레이하면 게임 데이터는 기기에만 저장되고, 저희 서버에는 회원님의 데이터가 없어요. 이 데이터를 지우려면 앱을 삭제하기만 하면 돼요. 계정이 있었다면 앱에서 더보기 → 설정 → 로그아웃으로 로그아웃한 다음, 앱을 삭제해서 기기에 남은 사본도 지워 주세요.

일부 데이터만 삭제하기

계정 전체가 아니라 일부 데이터만 지우고 싶다면 이것도 info@vidofood.de로 알려 주세요. 사용자 이름은 앱의 프로필에서 언제든지 직접 바꿀 수 있어요.

자세한 내용은 개인정보 처리방침(영어)에서 확인할 수 있어요.
